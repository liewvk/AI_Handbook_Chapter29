# AI Handbook – Chapter 29

A collection of Python examples for Chapter 29 of the AI Handbook.

## Files

- `AI_Handbook_Chapter29.py` — main project entry point
- `example29.1.py` through `example29.6.py` — chapter examples
- `AI_Handbook_Chapter29.pyproj` — Visual Studio Python project configuration
- `AI_Handbook_Chapter29.slnx` — Visual Studio solution file

## Requirements

- Python 3

## Running an Example

From the repository root, run any example with:

```bash
python example29.1.py
```

Replace `example29.1.py` with the desired chapter example.
